## 🧭 What this app does

mongodb-nosql-airbnb is a data platform for short-term rental data from Paris and Lyon. It helps you work with MongoDB data in a clear way. It also supports data checks, analysis, and high availability setups.

Use it to:

- store rental data in MongoDB
- review data with simple analytics
- test replica set failover
- use sharding for larger data sets
- prepare data for Power BI
- run Python-based data tasks

Open the data screen to see rental records such as:

### 🔍 Run analysis

Use the analysis tools to review:

- occupancy patterns

### 🗂️ Test database resilience

The app includes tools for:

- replica set setup
- backup and restore checks
- node failover tests
- read and write checks during outages

### 🌍 Use sharding

Sharding helps split data across multiple parts of the database. This app uses it for rental data across Paris and Lyon so larger data sets stay easy to manage.
